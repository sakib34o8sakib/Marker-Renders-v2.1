How to Use (Duration Markers)

The script operates specifically on Duration Markers (markers stretched across a range of frames). Normal single-frame markers are ignored. This ensures your quick notes do not clutter your render queue.

📌 How to create a Duration Marker in Resolve:

  • ● Place your playhead on the timeline, and press M on your keyboard to create a standard marker.
  • ● Double-click the marker icon to open the settings dialog.
  • ● Change the Duration field from 1 to any higher value (e.g., 120 frames), or hold Alt / Option and drag the marker's edge directly on your timeline.

Installation Process

A

Set Up Resolve Scripting Settings

Launch Resolve, open the main preferences window (DaVinci Resolve > Preferences > System > General). Set the External scripting using option to either Local or External, then click Save. Make sure you have python installed.

B

Place the Script File

Copy the script file marker render v2.1.py and paste it in this folder path:

%appdata%\Blackmagic Design\DaVinci Resolve\Support\Fusion\Scripts\Utility
~/Library/Application Support/Blackmagic Design/DaVinci Resolve/Fusion/Scripts/Utility/

⚠ Mac User First Launch Note: The script initially shows a Windows D:\ path when first loaded. Simply click Browse, set your preferred Mac directory, and the script will automatically remember your selection forever.

C

Open Workspace Scripts

In Resolve, go to the top bar and click Workspace > Scripts > marker render v2.1 to run the GUI.
